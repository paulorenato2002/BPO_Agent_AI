# Ferramentas Auxiliares

Scripts pequenos e avulsos que economizam tempo no trabalho do dia a dia.

**O que entra aqui:** uma coisa só, feita rápido, rodada à mão quando precisa.
Criar um lote de pastas, converter um arquivo, extrair uma aba de planilha,
renomear em massa, conferir uma lista.

**O que NÃO entra aqui:** processo com etapas, estado, fila ou integração —
isso é mini-sistema, fica em `../Mini-Sistemas/`.

A régua é simples: se dá para explicar o que faz em uma frase e roda do começo
ao fim sem guardar nada, é ferramenta auxiliar.

## Como organizar

Uma pasta por ferramenta, com um README de uma tela dizendo o que faz e como
roda. Linguagem é escolha de cada uma — Python, PowerShell, Node, o que
resolver melhor. Sem padronização forçada.

```
Ferramentas Auxiliares/
└── nome_da_ferramenta/
    ├── README.md
    └── (o código)
```
